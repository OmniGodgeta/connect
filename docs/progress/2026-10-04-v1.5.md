# 2026-10-04 — 1.5.0 released

1.5.0+6 is the current release. Asset `connect-1.5.0.apk` on tag `v1.5.0`. 1.4.0+5 (`72b184b`, `connect-1.4.0.apk`) stays up.

Shipped:

1. Volume-key hold-to-talk while a game is in front. Minimized Connect does not listen for speech.
2. A native bubble over the game with who is talking and a Talk button.
3. A gallery photo shared as JSON `{"t":"photo","jpeg":...}`. Painted faces stay the fallback. Image bytes never ride the PCM channel.
4. A local join/leave sound. The first roster after welcome is quiet.
5. A per-person volume slider, saved on the phone, applied on playback.

Emulator `pixel_api35` (`-no-audio`) checked the photo, the slider, the bubble hold, and a virtual volume key. The virtual key was consumed and the relay granted the floor. `adb shell input keyevent` does not reach `VolumeTalkService` on that emulator. Speaker playback was not heard. Two real phones are still an operator check. Friends also grant the volume-key accessibility service and display over other apps.

The relay user unit was restarted onto this `server/relay.py`. Do not run `tailscale serve reset`.
